# GitHub Project 每日看板截图

本目录只保存课程实践期间的真实 GitHub Project 页面截图。看板入口：

```text
https://github.com/users/tchen-0213/projects/1
```

每天站会结束并更新 Issues 和 Project 状态后截图，文件名统一为：

```text
YYYY-MM-DD-GitHub-Project.png
```

截图应能辨认日期视图、任务标题、负责人和状态。设计图、自动生成图片、文档截图或 GitHub Actions 截图不能代替每日 Project 看板截图；流水线截图如有则保存在 `../流水线截图/`。
