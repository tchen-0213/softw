当前任务以 GitHub Issues 为唯一工作项，以 GitHub Project 为主看板，以 GitHub Actions 为持续集成与部署证据。CodeArts 材料属于早期平台记录，不应再据此创建或流转新任务。

课程要求的个人贡献、成员权重和最终看板截图也应放在本目录。贡献与权重需要团队按真实分工确认，不能由代码仓库自动推断。
