# 软件工程基础实践 2026 夏交付总览

## 已形成的仓库交付物

| 类别 | 文件或目录 | 说明 |
| --- | --- | --- |
| 原系统代码 | `backend/`, `frontend/` | 保留前后端分离单体版本 |
| 微服务代码 | `services/` | API 网关及三个数据库隔离的真实业务微服务 |
| 容器化 | `backend/Dockerfile`, `frontend/Dockerfile`, `03_devops/docker-compose.yml` | 前端、后端、数据库容器化启动 |
| 微服务容器 | `03_devops/docker-compose.microservices.yml`, `services/*/Dockerfile` | 本地演示微服务拆分版本 |
| CI/CD | `.github/workflows/ci-cd.yml` | 自动测试、构建并推送七个镜像、部署 Kind 并执行健康检查 |
| 公网演示 | `.github/workflows/github-pages.yml`, `.devcontainer/` | GitHub Pages 前端连接 Codespaces 后端和 MySQL |
| Kubernetes | `03_devops/k8s/monolith`, `03_devops/k8s/microservices` | 单体和微服务部署 YAML、探针、HPA |
| 数据库初始化 | `03_devops/database/init/001_database.sql` | Docker MySQL 初始化脚本 |
| 测试 | `backend/tests`, `frontend/e2e`, `04_tests/performance/k6-core-flow.js` | 单元/安全测试、API 链路测试、Playwright E2E 与 k6 压测脚本 |
| 实验模板 | `03_devops/k8s/experiments` | HPA 与故障处理实验记录模板 |
| 管理材料 | `05_management/GitHub-Projects使用说明.md`, `05_management/敏捷开发记录.md`, GitHub Project 与 Issues | 当前看板、站会、任务和验收证据；CodeArts 文件作为历史资料保留 |
| 课程文档 | `02_docs/软件需求规格说明书.md`, `02_docs/软件概要设计说明书.md`, `02_docs/软件详细设计说明书.md` | 需求、概要、详细设计和三级模型 |

## 本地复现命令

```bash
npm run verify
npm run compose:up
docker compose -f 03_devops/docker-compose.microservices.yml up --build
```

## Kubernetes 演示命令

```bash
kind create cluster --name softw-practice --config 03_devops/k8s/kind-config.yaml
sh 03_devops/scripts/build-local-images.sh
kubectl apply -f 03_devops/k8s/monolith
kubectl apply -f 03_devops/k8s/microservices
kubectl -n softw-practice get pods
kubectl -n softw-microservices get pods
```
