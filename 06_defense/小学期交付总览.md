## 本地复现命令

```bash
npm run verify
npm run env:init
npm run compose:up
docker compose --env-file .env -f 03_devops/docker-compose.microservices.yml up --build
```

## Kubernetes 演示命令

```bash
kind create cluster --name softw-practice --config 03_devops/k8s/kind-config.yaml
sh 03_devops/scripts/build-local-images.sh
set -a && . ./.env && set +a
npm run k8s:deploy
kubectl -n softw-practice get pods
kubectl -n softw-microservices get pods
```
