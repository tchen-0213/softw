## 1. 背景与原系统

原系统是前后端分离的单体后端：React/Vite 前端、Express + Sequelize、MySQL 库 `shopping_platform`。业务覆盖校园购物与二手：注册登录、检索加购、下单支付发货收货、二手发布、店铺、评价、聊天议价、地址。

改造前用 Git 标签 `monolith-start` 固定基线，标签不再移动。单体三容器仍可启动，作为对照和中期演示入口。

## 2. 改造范围

小学期在原系统可运行的前提下完成：

1. **容器化**：前端 Nginx、Express 后端、MySQL 独立容器；Compose 文件在 `03_devops/`。
2. **CI/CD**：`.github/workflows/ci-cd.yml` 先测后构建 7 个版本化镜像，再 Kind 部署与健康检查；测试失败不进入发布。
3. **Kubernetes**：单体与微服务两套 YAML，含探针、HPA；部署与回滚脚本在 `03_devops/scripts/`。
4. **微服务**：按业务能力拆成 user-service、product-service、order-service，外加 API 网关。网关不计入 3 个业务服务。

公网演示为 GitHub Pages 前端连接 Codespaces 后端。Pages 与本机 Docker 使用不同数据库，数据和登录态不同步。

## 3. 服务划分与数据归属

```text
前端 → API Gateway
        ├─ user-service    → softw_users
        ├─ product-service → softw_catalog + 上传文件
        └─ order-service   → softw_orders
```

划分按身份、可交易资源和交易过程，不按 12 个用例拆成 12 个服务。评价、聊天、图片当前在商品服务。每张业务表只由一个服务写入；订单保存商品项和地址快照，不跨库联表。库存预留/释放/完成走商品服务内部接口，按 `reservationId` 幂等。网关超时返回 HTTP 503，不编造成功。

图与接口表见 `02_docs/images/33-MS-SPLIT.svg`、`02_docs/微服务接口与数据归属.md`。

## 4. 测试与流水线门禁

最终验收用例为 UC01–UC12，重点汇报 UC01、UC02、UC04。2026-09-02 分项结果：

- 后端单元/安全/控制器：80 通过，1 个 API 父入口按设计跳过
- 前端 Vitest：100/100；覆盖率语句 94.42%、分支 81.83%、函数 92.34%、行 94.42%
- 单体 MySQL API：32/32
- Playwright E2E：6/6（Compose 与 Kind）
- 微服务静态/公共层 18/18，隔离集成 22/22，网关 API/E2E 15/15
- 交付与实验证据门禁 18/18

流水线 `softw-ci-cd` 用 job 依赖保证测试未通过不得构建镜像和部署。原始报告以 Actions #77 为准。

## 5. 性能对比与云原生实验

**性能（2026-08-28）**：同机、同 Docker、同 200 条商品、同一 k6 脚本，对列表/搜索/详情在单体与微服务上各跑 3 次，共 18 组，错误率 0%。在该条件下微服务查询吞吐更高、延迟更低，但 CPU/内存总和更高。例如列表吞吐 +61.9%、平均延迟 −38.6%、CPU +55.2%。不能写成「微服务架构天然更快」。原始文件在 `04_tests/reports/performance/raw/interface-comparison-2026-08-28/`。

**HPA（2026-09-01）**：Kind 上商品服务副本实测 `1 → 3 → 5`，压力下降后回到 1。

**故障**：停止商品服务后，商品接口 503；订单依赖检查 206 并给备用提示；网关、用户、订单服务仍存活，恢复后无残留。

## 6. 已知限制

- 本地 `localhost:8080` 与 GitHub Pages 接不同后端，订单和评价不会自动对齐。
- 店铺认证图片须为 jpg/png/gif/webp，前端 Nginx 对上传体积较严，宜用小图演示。
- CORS 白名单含 `http://localhost:8080`，用 `127.0.0.1` 打开可能被拒。
- 评价页已改为先加载订单与历史评价，已评价项只读；勿再按空白占位表单描述。
- Helm 未使用，Kubernetes 以 YAML 提交。

原系统标签可复现；微服务版本三个业务库隔离、网关统一入口；容器、CI、K8s、HPA、故障和三次压测均有原始记录。文档可编辑源在 `02_docs/`，给老师的 Word 与 PDF 在 `06_defense/export/`。站会简报、Project 截图、PPT、权重确认由组员按实际补充。
