# 答辩提纲

## 4 分钟项目与架构说明

1. 项目背景：购物与二手交易平台。
2. 原系统：React/Vite 前端、Express 后端、MySQL。
3. 小学期改造：容器化、CI/CD、Kubernetes、微服务拆分。
4. 服务划分：网关、用户服务、商品服务、订单服务。

## 7 分钟现场演示

1. 运行 `npm run verify` 展示测试和构建。
2. 运行 `docker compose up --build` 展示单体容器化。
3. 查看 `/api/health`。
4. 应用 `k8s/microservices` 展示网关和 3 个业务服务。
5. 访问 `api-gateway /health`、`/version` 和一个业务接口。
6. 触发 `product-service` 缩容为 0，访问订单依赖健康接口展示降级。
7. 展示 HPA 配置和压测脚本。

## 4 分钟问答准备

- 为什么这样拆服务。
- 每张表归谁管理。
- 测试失败为什么会阻断部署。
- 微服务版本为什么可能比单体慢。
- 本人负责的任务、提交和证据。
