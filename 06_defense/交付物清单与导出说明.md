# D9-02 交付物清单与导出说明

## 九类交付物

| 类别 | 证据 |
| --- | --- |
| 需求、概要、详细设计 | `02_docs/` 源文件及 `06_defense/export/` DOCX/PDF |
| 测试与追溯 | `02_docs/测试文档.md`、`04_tests/`、`02_docs/业务场景用例清单与追溯表.md` 及 DOCX/PDF |
| 模型源 | `02_docs/images/` 的 42 张 SVG |
| 工程与部署 | `03_devops/`、`.github/workflows/`、各 Dockerfile |
| 原始报告 | `04_tests/reports/` 的结构化数据和运行记录 |
| 项目管理 | `05_management/` |
| 答辩材料 | `06_defense/` |
| AI 与许可证 | `06_defense/AI工具与开源来源记录.md` |
| 一致性证据 | `06_defense/export/manifest.json` |

重新导出与审计：

```text
npm run export:deliverables
npm run audit:deliverables
```

Markdown 是唯一编辑源。导出脚本使用 Pandoc 生成 DOCX/HTML，使用 Chromium 生成 PDF，并把 SVG 渲染为 PNG 嵌入 DOCX。重点讲解用例为 UC01 注册登录、UC04 订单状态流转、UC08 议价会话。
