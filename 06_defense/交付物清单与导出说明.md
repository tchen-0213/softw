重新导出前，准备 Node.js 22 或更新版本、Python 3，以及前端 Playwright 浏览器：

```text
npm ci
npm --prefix frontend ci
npm --prefix frontend exec playwright install chromium
python -m pip install python-docx pymupdf
```

重新导出与审计：

```text
npm run export:deliverables
npm run audit:deliverables
```

Markdown 是唯一编辑源。当前脚本使用 python-docx 生成 DOCX、PyMuPDF 将 SVG 转为嵌入 Word 的 PNG、marked 生成 HTML、Playwright Chromium 生成 PDF。15 组交付文件同步到 `06_defense/export/`、`提交包/`，适用 PDF 同步到 `02_docs/pdf/`；`manifest.json` 记录源文件与导出文件哈希。

只更新选定文件时，PowerShell 可执行 `$env:EXPORT_DOCUMENTS='测试计划,测试报告-小学期'` 后再运行导出命令；完成后执行 `Remove-Item Env:EXPORT_DOCUMENTS`。需要指定 Python 时使用 `CODEX_PYTHON_PATH` 环境变量。未设置选择项时导出全部 15 组，不再依赖 Pandoc。

当前测试说明统一为 Playwright 42 项（12 个主流程、27 个 ALT/ERR、3 个组合流程），保留独立和组合筛选方式。重点讲解用例为 UC01 注册登录、UC02 搜索、UC04 订单状态流转。
