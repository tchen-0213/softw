## 第 7 页 · 三个业务微服务

**必须出现**

```
前端 → API Gateway（统一入口，不算业务服务）
        ├─ user-service    → softw_users
        ├─ product-service → softw_catalog + uploads
        └─ order-service   → softw_orders
```

| 服务 | 职责 | 划分依据 |
| --- | --- | --- |
| user-service | 注册登录、资料、密码、地址、角色、信用 | 身份与账号生命周期 |
| product-service | 商品、二手、店铺、评价、聊天、议价、图片、库存 | 可交易资源 |
| order-service | 下单、支付、取消、发货、收货、状态机 | 交易过程与历史快照 |
| API Gateway | 路由、JWT 透传、超时、CORS、503 | 入口，不计入 3 |

- **不是** 12 个用例拆 12 个服务
- 每张业务表只由一个服务写入；订单保存商品项和地址 **快照**，不跨库联表

## 第 8 页 · 接口、表归属、失败处理

**必须出现（表要全）**

网关前缀：`/api/users` `/api/addresses` → user；`/api/products` `/api/secondhand` `/api/shops` `/api/evaluations` `/api/chats` `/api/uploads` → product；`/api/orders` → order。

| 库 | 表 | 唯一写入 |
| --- | --- | --- |
| softw_users | Users, Addresses | user-service |
| softw_catalog | Products, Shops, Evaluations, ChatConversations, ChatMessages, InventoryReservations | product-service |
| softw_orders | Orders | order-service |
| 文件卷 | uploads/ | product-service |

失败处理：

- 网关超时/断开 → HTTP **503**，不伪造成功
- 库存预留失败 → 不创建订单
- 释放/完成按 reservationId **幂等**
- 商品服务停止：商品接口 **503**「依赖服务暂不可用」；订单依赖检查 **206**「商品信息暂不可用，订单查询保持可用」；网关/用户/订单仍 **1/1**
- 内部接口要 `X-Internal-Token`，外部不能直接打库存/信用/购买证明
