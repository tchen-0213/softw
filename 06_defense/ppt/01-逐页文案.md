## 第 3 页 · 微服务拆分

标题：按业务能力拆成 3 个业务服务，网关不计入数量  
副标题：划分围绕身份、交易标的、交易过程，不按用例数机械拆。

React 前端 → API Gateway →

- user-service：注册登录、资料、地址、角色、信用
- product-service：商品、二手、店铺、评价、聊天、库存、上传
- order-service：下单、支付、取消、发货、收货、状态机

网关：统一入口与路径转发；JWT、Request-ID、幂等键透传；超时返回 **503**，不伪造业务成功。

可补前缀：`/api/users` `/api/addresses` → user；商品/二手/店/评价/聊天/上传 → product；`/api/orders` → order。
