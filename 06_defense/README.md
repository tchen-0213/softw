# 06_defense 答辩材料

本目录用于最终答辩和演示材料：

- `小学期交付总览.md`：按任务书快速定位全部交付物。
- `最终交付核查清单.md`：九类交付路径、评分项和仍须人工完成的事项。
- `技术总结报告.md`：改造、测试、实验与限制；正式 Word/PDF 在 [`提交包/`](../提交包/)。
- `答辩提纲.md`：汇报顺序、PPT 建议数字和现场命令。
- 最终 PPT（`.pptx`）由组员放入本目录。

答辩前先在仓库根目录运行：

```bash
npm run verify
npm run env:init
npm run compose:up
```
