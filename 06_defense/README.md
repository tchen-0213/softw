# 06_defense 答辩材料

本目录用于最终答辩和演示材料：

- `小学期交付总览.md`：按任务书快速定位全部交付物。
- `最终交付核查清单.md`：九类交付路径、评分项和仍须人工完成的事项。
- `交付物清单与导出说明.md`：export 文件夹里 Word/PDF 怎么来的。
- **`export/`：给老师的 Word 和 PDF，先看 `export/00-请先看这个.txt`。**
- `技术总结报告.md`：改造、测试、实验与限制。
- `答辩提纲.md`：10 分钟口径；PPT 只覆盖架构 3 分钟。
- `13组-摸鱼-最终答辩.pptx`：7 页内容底稿。
- `ppt/`：给 Image 2 的边界/偏好、逐页必须出现的内容、数字出处。

答辩前先在仓库根目录运行：

```bash
npm run verify
npm run env:init
npm run compose:up
```
