# 安全加固方案

## 1. 目标

本方案用于支撑小学期对安全性非功能属性的要求。目标是在现有 Express + JWT + MySQL 架构基础上提升认证、授权、输入校验、上传、限流、错误处理和配置安全。

## 2. 当前风险

| 风险 | 说明 | 优先级 |
| --- | --- | --- |
| JWT 默认密钥 | 代码中存在默认 `your-secret-key` 兜底，生产环境不安全 | 高 |
| 参数校验不足 | 多数接口直接使用请求体和查询参数 | 高 |
| 上传安全不足 | 需要限制文件类型、大小和路径 | 高 |
| 接口限流缺失 | 登录、注册、上传等接口易被刷 | 高 |
| 错误信息暴露 | 部分接口返回 `error.message` | 中 |
| 权限审计不足 | 订单、商品、店铺操作需确认用户边界 | 高 |
| 安全响应头缺失 | 缺少 helmet 等基础防护 | 中 |

## 3. 加固任务

### 3.1 JWT 配置安全

要求：

- 生产环境必须配置 `JWT_SECRET`。
- 禁止生产环境使用默认密钥。
- JWT 过期时间通过环境变量配置。

建议策略：

```text
development: 允许本地默认值，但打印警告
production: 未配置 JWT_SECRET 时直接启动失败
```

### 3.2 参数校验

建议引入 `express-validator` 或 `joi`。

重点接口：

- 注册：用户名、邮箱、手机号、密码。
- 登录：邮箱、密码。
- 商品发布：名称、价格、库存、分类。
- 订单创建：商品列表、数量、收货地址。
- 评价：评分、内容。

### 3.3 限流

建议使用 `express-rate-limit`。

限流策略：

| 接口 | 策略 |
| --- | --- |
| 登录 | 每 IP 每 15 分钟最多 20 次 |
| 注册 | 每 IP 每小时最多 10 次 |
| 上传 | 每 IP 每 10 分钟最多 30 次 |
| 普通 API | 每 IP 每分钟最多 120 次 |

### 3.4 上传安全

要求：

- 限制最大文件大小。
- 只允许图片和必要的视频格式。
- 使用随机文件名。
- 禁止用户控制保存路径。
- 不允许上传脚本文件。

允许类型建议：

```text
image/jpeg
image/png
image/gif
image/webp
video/mp4
```

### 3.5 权限控制

需要审计：

- 用户只能查看和修改自己的个人资料。
- 用户只能修改自己发布的商品。
- 买家只能查看自己的订单。
- 卖家只能处理包含自己商品的订单。
- 店铺认证和管理只能由店铺所有者或管理员操作。
- 评价只能由相关订单用户创建。

### 3.6 CORS 安全

要求：

- 开发环境允许本地前端地址。
- 生产环境使用明确白名单。
- 不使用 `*` 配合 credentials。

### 3.7 错误处理

建议建立统一错误处理中间件：

- 开发环境可返回详细错误。
- 生产环境只返回通用错误信息。
- 错误详情写入服务端日志。

### 3.8 安全响应头

建议使用 `helmet`：

```text
X-Content-Type-Options
X-Frame-Options
Referrer-Policy
Content-Security-Policy
```

## 4. 安全测试用例

| 测试项 | 方法 | 期望 |
| --- | --- | --- |
| 弱密码注册 | 使用过短密码注册 | 返回参数错误 |
| 重复邮箱注册 | 使用已有邮箱注册 | 返回用户已存在 |
| 未登录访问个人资料 | 不带 token 请求 | 返回 401 |
| 越权修改商品 | 修改他人商品 | 返回 403 |
| 非法文件上传 | 上传 js/php 文件 | 拒绝上传 |
| 高频登录 | 短时间多次请求登录 | 触发限流 |
| 非法 CORS 来源 | 使用未授权 Origin | 拒绝跨域 |

## 5. 验收标准

- 完成安全加固方案和安全测试记录。
- 关键接口具备参数校验。
- 登录、注册、上传等接口具备限流策略。
- 上传接口限制类型和大小。
- 生产环境不允许默认 JWT 密钥。
- 权限敏感接口通过越权测试。

## 6. 已落地加固项

当前代码已完成以下加固：

- 新增统一请求 ID：响应头返回 `X-Request-Id`。
- 新增基础安全响应头：`X-Content-Type-Options`、`X-Frame-Options`、`Referrer-Policy`、`Permissions-Policy`。
- 新增全局限流中间件，默认每 IP 每分钟 120 次请求，可通过环境变量调整。
- 生产环境启动时校验 `JWT_SECRET`，禁止使用默认密钥。
- JWT 过期时间使用 `JWT_EXPIRES_IN` 环境变量。
- 注册和登录接口增加基础参数校验。
- 上传接口限制文件大小、MIME 类型和扩展名，仅允许 jpg、png、gif、webp。
- 统一错误处理中间件避免生产环境暴露内部错误细节。
