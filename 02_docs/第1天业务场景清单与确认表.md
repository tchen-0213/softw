### UC01 完成平台注册并建立可用登录身份

| 项目 | 说明 |
| --- | --- |
| 对应需求 | REQ01 用户身份建立与认证 |
| 参与者 | 游客、注册用户 |
| 触发条件 | 游客希望使用下单、发布、聊天等需要身份的功能 |
| 前置条件 | 用户未登录；注册时邮箱和用户名未被占用 |
| 主成功流程 | 1. 游客填写用户名、邮箱、手机号和密码。2. 系统校验必填项、邮箱格式和密码长度。3. 系统创建用户并加密保存密码。4. 系统返回令牌和用户信息。5. 用户使用邮箱和密码再次登录。6. 系统验证密码并允许访问个人中心。 |
| 备选流程 | 已注册用户可跳过注册，直接使用正确邮箱和密码登录；登录后可更新昵称、手机号或密码。 |
| 异常流程 | 缺少必填项、邮箱格式错误、密码过短或用户已存在时拒绝注册；用户不存在、密码错误或令牌无效时拒绝登录或访问个人中心。 |
| 可验证结果 | 返回有效 JWT；个人资料接口和个人中心可访问；密码不以明文返回。 |

### UC04 完成订单创建、支付、发货和收货

| 项目 | 说明 |
| --- | --- |
| 对应需求 | REQ04 订单交易闭环 |
| 参与者 | 买家、卖家 |
| 触发条件 | 买家从购物车或商品详情发起结算 |
| 前置条件 | 买家已登录；商品在售且库存充足；买家已选择有效地址 |
| 主成功流程 | 1. 买家确认商品、数量、地址和支付方式。2. 系统复核商品状态与库存。3. 系统创建待付款订单并扣减库存。4. 买家执行模拟支付，订单变为待发货。5. 卖家填写物流公司和单号并发货，订单变为待收货。6. 买家确认收货，订单变为已完成。7. 二手商品售罄时变为已售出。 |
| 备选流程 | 买家可在允许的状态取消订单，系统恢复库存；普通商品可购买多个数量；二手商品库存归零后进入已预订或已售出状态。 |
| 异常流程 | 商品不存在、不可售或库存不足时拒绝创建；非买家不能支付或确认收货；非卖家不能发货；错误订单状态不能重复支付、发货或确认；物流信息不完整时拒绝发货。 |
| 可验证结果 | 订单状态按待付款、待发货、待收货、已完成转换；支付状态、物流记录和库存变化可查询。 |
