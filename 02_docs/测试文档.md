# 测试计划与执行说明

更新日期：2026-09-03。本文保留当前测试范围与执行方式；分项结果以 `04_tests/README.md` 和 `04_tests/reports/tests/测试报告-小学期.md` 为准。

## 1. 环境与工具

测试使用 Node.js 内置 `node:test`、Vitest + Testing Library + jsdom、Playwright Chromium 和 k6。纯单元/静态测试不需要业务容器；真实 API、浏览器测试需要先启动对应 Compose 服务。单体页面为 `http://localhost:8080`，API 为 `http://127.0.0.1:3001`；微服务页面为 `http://localhost:8082`，网关为 `http://127.0.0.1:8081`。

以下 curl 多行示例适用于 Bash。Windows PowerShell/CMD 的测试命令见 `04_tests/README.md`，两种终端的环境变量语法不能混用。

## 3. 当前测试计划

### 3.1 测试目标

小学期测试重点从原有功能正确性扩展到非功能属性验证，包括接口稳定性、回归测试、性能测试、安全测试和部署验证。

测试目标：

- 验证注册、登录、商品、订单、店铺、评价、聊天等核心功能可用。
- 验证重构后接口兼容原有前端调用。
- 验证高频接口在一定并发下保持可接受响应时间。
- 验证关键接口具备基础安全防护。
- 为最终汇报提供测试记录和缺陷闭环证据。

### 3.2 测试范围

| 类型 | 范围 | 负责人 |
| --- | --- | --- |
| 功能测试 | UC01-UC12：注册登录、商品、购物车、订单、二手、店铺、评价、聊天、地址、物流、取消和公开店铺 | 赵紫嫣 |
| 接口测试 | 后端 REST API | 赵紫嫣、浦灵一 |

| 性能测试 | 商品列表、搜索和详情，单体/微服务同数据各三轮；另有订单查询与索引实验 | 剧博洋 |
| 安全测试 | 鉴权、越权、上传、限流、参数校验 | 浦灵一 |
| 部署验证 | GitHub Actions、Docker Compose、Kind 和 Codespaces | 陈子正 |

### 3.3 回归测试用例

| 编号 | 用例 | 步骤 | 期望 |
| --- | --- | --- | --- |
| TC01 | 用户注册登录 | 注册新用户并登录 | 返回 token，可进入个人中心 |
| TC02 | 商品浏览搜索 | 检索并筛选排序 | 结果、分页与空结果正确 |
| TC03 | 商品详情与购物车 | 进入详情、加购并调整数量 | 商品信息、数量及库存边界正确 |
| TC04 | 创建订单 | 登录、选商品、选地址并下单 | 订单创建，库存变化，身份和状态受约束 |
| TC05 | 二手发布 | 发布、修改、删除二手商品 | 资料持久化，卖家权限有效 |
| TC06 | 店铺管理 | 认证并更新店铺信息 | 店铺资料保存，权限正确 |
| TC07 | 评价商品 | 对已完成订单评价 | 评价可查，重复和未完成订单被拒绝 |
| TC08 | 聊天议价 | 买家议价，卖家接受或拒绝 | 会话参与者隔离；成交价和一次性使用另由 API 断言 |
| TC09 | 收货地址 | 新增、修改、删除、切换默认地址 | 持久化且默认项唯一 |
| TC10 | 订单与物流 | 查看本人订单和物流 | 状态与物流正确，越权被拒绝 |
| TC11 | 取消订单 | 取消允许状态的订单 | 库存恢复，重复操作不二次恢复 |
| TC12 | 公开店铺 | 游客查看店铺、信用与在售商品 | 无需登录，空/不存在店铺正确处理 |

Playwright 包含 12 个独立主流程、27 个 ALT/ERR 和 3 个连续组合流程。每项自行准备数据，不依赖其他编号先执行。组合流程为 TC01/02/03/04/09、TC05/06 和 TC10/11。

### 3.4 性能测试计划

正式对比固定同一批商品和 k6 脚本，对商品列表、搜索、详情在单体/微服务入口各运行 3 次，共 18 组。并发、时长与阈值以 `04_tests/performance/k6-interface-comparison.js` 及对应原始输出为准，不沿用未执行的旧计划参数。

记录指标：

- QPS。
- 平均响应时间。
- P95 响应时间。
- 错误率。
- 数据库连接是否稳定。
- 服务是否出现异常日志。

### 3.5 安全测试计划

| 编号 | 测试项 | 方法 | 期望 |
| --- | --- | --- | --- |
| SEC-01 | 未登录访问 | 不带 token 请求个人资料 | 返回 401 |

| SEC-06 | 非法 CORS 来源 | 使用未授权 Origin 请求 | 拒绝跨域 |
