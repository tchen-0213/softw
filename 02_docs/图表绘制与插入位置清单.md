# 图表绘制与插入位置清单

## 1. 使用说明

三份说明书正文嵌入浏览器实渲 PNG（`02_docs/images/png/`）。Mermaid SVG 含 CSS/`foreignObject`，直接放进 Word 或系统预览会变成黑块、箭头消失。模型源仍是 `02_docs/models/*.mmd` 与 `02_docs/images/*.svg`。

建议导出规则：

- 优先 SVG；必须使用 PNG 时宽度不少于 1800px。
- 图中文字保持可读，不截断参与者、方法名或异常分支。
- 图放在对应小节标题和解释文字之后，不集中堆在附件。
- 每张图下方保留图号，例如“图 SYS-SEQ04 订单交易闭环系统级顺序图”。
- Mermaid 源码是可编辑模型源文件，SVG 是说明书中的展示文件，两者均应提交。

## 4. 三级图的绘制边界

| 层次 | 应出现 | 不应出现 |
| --- | --- | --- |
| 系统级 `SYS-*` | 用户/外部参与者、购物平台黑盒、业务结果和异常分支 | Controller、Model、SQL、函数名 |
| 组件级 `COMP-*` | 页面、API Client、路由、中间件、控制器、模型、数据库 | 过细的局部变量和每一行实现代码 |
| 对象级 `OBJ-*` | 具体实例、函数、ORM 方法、事务、关键规则 | 与代码不存在的 Service/DAO 或外部系统 |
