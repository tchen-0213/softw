# 2026-08-30 D6-01 三业务微服务验收记录

## 验收结论

Issue `D6-01` 的本地实现与部署验收已完成：user-service、product-service、order-service 三个业务服务能够独立测试和构建，Compose 与 Kubernetes 均能启动完整拓扑；三库实际表归属与设计一致；跨服务连接失败统一返回 HTTP 503，商品服务不可用时不会写入半成品订单。

## 本次补齐的缺口

1. GitHub Actions 微服务矩阵由共用 `softw_test` 改为按服务创建并使用 `softw_users_test`、`softw_catalog_test`、`softw_orders_test`，避免共享测试库掩盖边界错误。
2. 内部 HTTP 客户端将连接失败映射为 HTTP 503，与超时和网关降级口径一致。
3. order-service 增加依赖服务停止后的断言：请求返回 503，订单表记录数不增加。
4. Compose 为三个业务服务、网关和微服务前端声明 `2.0.0` 镜像标签，不再依赖隐式 `latest`。
